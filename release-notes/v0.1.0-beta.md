First public beta of EQify.

**Install:** add `https://github.com/parthsharma365628/eqify-releases` to [Obtainium](https://github.com/ImranR98/Obtainium) for automatic updates, or download `EQify-0.1.0-beta.apk` below. Uninstall any older EQify build first. See the [README](https://github.com/parthsharma365628/eqify-releases#before-and-after-installing) for the Play Protect and notification access steps.

### What's in it
- Automatic genre EQ for Spotify, YouTube Music, YouTube and Apple Music
- Customisable genre curves and your own presets (share by code, file or QR)
- AutoEQ headphone correction with automatic Bluetooth, USB-C and wired detection
- Bass boost, output protection, themes and a Quick Settings tile

### Known issues
- Force mono doesn't work on some phones (Android gives no way to check).
- Genre detection depends on song metadata and can be wrong; use **Change genre** on Home to correct it for that song.
